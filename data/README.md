# Data (not distributed with this repository)

JA-NET uses two external datasets. Download them and place them in this folder:

- `mixturesoldb.csv` - MixtureSolDB (Nature Sci. Data, s41597-026-07047-z)
- `bao27k.xlsx` - Bao et al. 2024 (J. Cheminform., s13321-024-00911-3)

The first run builds a cached `feat.npz` here automatically.
